# Mapping-algorithm
A project of mapping algorithm for a simulated rescue robot


Remplir le fichier data/map.txt avec les données de la carte :
  -> nombre de lignes    : n<br>
  -> nombre de colonnes  : m\n
  -> première ligne      : 111111...1
  -> deuxième ligne      : 100010...1
        .
        .
  -> n-ième ligne        : 111111...1

NB : 1 : mur ; 0 : case accessible


Executer le programme : ./main \<chemin ABSOLU du fichier map.txt>
